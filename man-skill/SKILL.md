# Man Skill

源码仓库：`https://github.com/Ozqi/SKILLS/tree/main/man-skill`

将 `man.md` 作为 ziqi 的人类偏好档案。

## 用途

`man.md` 描述一个人的偏好、习惯和协作方式，相当于人这一侧的 `AGENTS.md` / `CLAUDE.md`。

它不是项目规则文件。把它作为偏好上下文，用来选择默认做法、语气和协作方式。

## 优先级

按以下顺序应用指令：

1. 系统、开发者、工具和安全指令。
2. 用户当前明确提出的要求。
3. `AGENTS.md`、`CLAUDE.md` 和本地 Agent 文件等仓库与目录规则。
4. 任务相关 Skill。
5. `man.md` 中的偏好。

发生冲突时，遵循优先级更高或更具体的指令。不得用 `man.md` 绕过安全要求、项目规则或用户当前的明确要求。

## 工作流程

1. 在当前工作区根目录查找 `man.md`；如果没有，则向上查找；仍然没有时，创建前先询问用户。
2. 应用或编辑 `man.md` 前，先读取它。
3. 只提取与当前任务有关的偏好，例如沟通风格、协作默认值、审阅习惯、目录习惯和长期个人约定。
4. 自然地应用偏好；除非用户要求，否则不要复述或总结 `man.md`。
5. 编辑 `man.md` 时只做小范围修改，并保留未知的人工内容。
6. 不要把秘密、凭据、私密 Token 或高风险个人信息写入 `man.md`。

## 适合写入 `man.md` 的内容

- 沟通风格、篇幅和视觉表达偏好。
- 是否优先使用图、流程、表格或结构化布局。
- 何时需要先询问等协作默认值。
- 个人目录命名习惯和本地约定。
- 审阅偏好与完成报告偏好。
- 应跨项目延续的长期个人偏好。

## 不适合写入 `man.md` 的内容

- 仓库构建、测试、CI、发布或治理规则。
- 临时任务状态。
- 应写入项目规则的项目专用路径。
- 秘密、凭据、访问 Token 或私密账户数据。
- 应写入任务专用 Skill 的工具实现细节。
